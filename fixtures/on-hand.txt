#   - a title and a date line above the header, which every PioneerRx report prints;

#   - a UPC rather than an NDC on a front-shop line, which is a code the reader keeps but cannot
#     price against NADAC;
#   - a row with no quantity at all, which must be skipped rather than filed as zero;
#   - an inventory group, so the dispensing shelf can be told from the front shop;
#   - a manufacturer that wrapped onto a line of its own and still arrived at the full column
#     width, which is the tail the narrow-line test cannot catch. It carries no code and no
#     quantity, so it is a tail and not a record whose NDC went missing.
