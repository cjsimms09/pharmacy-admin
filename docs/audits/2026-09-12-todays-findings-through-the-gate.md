### 5. A return credit costs the whole invoice

```
OBSERVATION  Three McKesson lines, two purchases and one -$2.32 return credit: 2 lines read,
             unreadable 0, sum $741.43 against a printed $739.11, reconciles false — and
             invoices.ts:1412 then stores nothing for the invoice. $2.32 costs $743.75 of line
             detail. Brackets, (2.32), behave the same.
SHOULD BE    A wholesaler invoice can carry a return credit — short-dated, damaged, recalled stock
             goes back and is credited on the same document. A credit is a negative line, and the
             invoice still adds up when it is read as one. IPC's own credit note proves the house
             understands this; IPC_CREDIT reads it and an IPC mixed invoice reconciles today.
DIFFERENCE   Yes, for McKesson, IPD and ParMed, which are most of the paper.
```

### 7. The buy list's controlled gate asks the weakest of three sources

```
OBSERVATION  controlledNdcs selects { ndc11, itemClass } and falls back to a name list. itemClass
             is set by 1 of 5 readers (McKesson); IPD's oxycodone line comes out itemClass null,
             controlled TRUE — a stored column the gate does not select. drug_directory.dea_schedule
             holds the FDA's per-NDC answer and is not consulted.
SHOULD BE    A page that states it excludes controlled substances must use the best evidence of
             schedule available to it. DEA schedule is a property of the drug, published per NDC by
             the FDA, and stated on the invoice by the supplier — both stronger than matching a
             name. The module's own asymmetry says the same: a wrong inclusion is the expensive one.
DIFFERENCE   Yes. Fairly: the C-II name list is exhaustive by design and a III-V needs no 222 or
             CSOS, so this is not a CII in the cart — it is a controlled substance able to appear
             on a page whose premise is that it carries none.
```
