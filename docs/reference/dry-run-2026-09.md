# The September 2026 dry run — scorecard

**The owner, 15 September 2026:** *"books start on 10/01 but we need to do a complete dry run this month to troubleshoot
EVERYTHING and make sure everything works starting 10/01"*.

September runs as if it were live. Every feed, reader, match, report and check has to work on September's own real
documents, and every fault found is fixed before 1 October. This page is kept by session 2 and updated each time
something passes or fails. Session 1 reports each live feed as it runs.

Evidence refers to `docs/reference/money-map.md` (checkpoints and gaps), `docs/reference/claim-lifecycle.md` (the
money standard and its September measurement) and commits. Every "passed" was re-run on a fresh snapshot of the live
database; nothing was checked on live.

## States

| state | meaning |
|---|---|
| **PASSED — September real** | ran on September's own real documents and every check held |
| **PASSED — sample** | proven on a real document from another month (e.g. August's bank statement); September's own has not run yet |
| **FIXING** | ran, a fault was found, and the fix is written but not yet merged and re-run |
| **FAILING** | ran, a fault was found, and no fix exists yet |
| **SUSPECT** | ran, and something looks wrong, but it is not proven: it waits on the check named |
| **NOT YET RUN** | never run on any real document |
| **AWAITING OWNER** | cannot move until the owner acts or decides |
| **AFTER MONTH END** | the document is issued after 30 September. The owner decided (15 Sept) that these run in early October, alongside the live books |

2. **September fills paid in October.** When a plan pays in October for a prescription filled in September:
   - **as opening receivables:** September's unpaid claims are carried into the October books and the October payment
     settles them;
   - **as October cash only:** the money counts as October cash and settles nothing, and September's unpaid claims
     are never on the October receivables report. This is how the site treats pre-books money today.
